# 优惠券（惊喜优惠）

## 1. 数据模型

### voucher_stock（库存）

| 字段 | 说明 |
| --- | --- |
| type | 优惠券类型，整数枚举，见 VoucherType |
| stock | 剩余库存 |
| description | 满减规则描述，如「满10元减2元」 |
| last_change_time | 上一次扣减库存的时间 |

### voucher_record（领取记录）

| 字段 | 说明 |
| --- | --- |
| voucher_id | 雪花 ID（高并发下应用侧生成，避免自增热点） |
| user_id | 所属用户（UUID / 001 / 1001） |
| voucher_type | 类型 |
| expire_time | 过期时间（领取后 48 小时） |
| status | available / used / expired |
| created_at | 领取时间 |

## 2. 类型与库存

| type | 规则 | 初始库存 |
| --- | --- | --- |
| 1 | 满10减2 | 100 |

| 3 | 满10减5 | 25 |
| 4 | 满15减2 | 100 |
| 5 | 满15减3 | 50 |
| 6 | 满15减5 | 25 |
| 7 | 满15减7 | 12 |
| 8 | 满20减5 | 100 |

规则：同一满减价位第一档 100 张，每往后一档减半。

## 3. 领取

```
POST /api/vouchers/{type}/claim
→ { voucherId, type, description, expireTime, remainingStock }
```

事务内三件事：

1. `UPDATE voucher_stock SET stock = stock - 1 WHERE type = ? AND stock > 0`
   —— 单条带条件更新，影响行数为 0 即"已领完"，不需要先查再减；
2. 写 `voucher_record`（雪花 ID + 48 小时过期）；
3. 往 `local_message` 登记一条到期消息（`voucherexpire:{voucherId}`，`deliver_at = expireTime`）。

约束：同一用户同一类型只能持有一张可用券，重复领取返回 `VOUCHER_ALREADY_CLAIMED`。

## 4. 过期（RocketMQ 延迟消息）

```
领取 ──写 local_message(deliver_at = +48h)──▶ worker 重发 job（每 10s 扫一次）
      ──到点投递到 voucher-expire──▶ VoucherExpireConsumer
      ──UPDATE voucher_record SET status='expired' WHERE status='available'──▶ 幂等结束
```

- topic 类型必须是 DELAY（`message.type=DELAY`），否则 broker 拒收定时消息；
- 幂等靠 `WHERE status='available'`：重复投递、已被使用都不会误改；
- 过期时长由 `dash.voucher.expire-hours` 控制（默认 48）。

## 5. 前端

广场左侧（任务列表上方）新增「惊喜优惠」横条：

- 每张券显示减免金额、满减规则、剩余张数、领取按钮；
- 领取成功用 `dash:notice` 弹出提示，并就地更新剩余库存；
- 库存为 0 时按钮禁用、卡片置灰。
