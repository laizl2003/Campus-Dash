# 校内快递驿站

校内共 3 个快递驿站，营业时间 **08:00-20:00**，凭取件码或手机尾号取件，超过 3 天未取会退回。

## 西区小木屋

- 位置：西校区北门内侧，6 号楼背后
- 别名：小木屋、西区菜鸟、西区菜鸟驿站
- 营业时间：08:00-20:00
- 备注：西区唯一驿站，中通、圆通、申通、韵达都到这里；大件在屋后棚下

## 东区菜鸟驿站

- 位置：东校区东门内，301 号楼旁
- 别名：东区菜鸟、东区驿站
- 营业时间：08:00-20:00
- 备注：东区宿舍区最近的驿站，顺丰、京东也在此代收

## 中区菜鸟驿站

- 位置：中校区北门内，6 号楼对面
- 别名：中区菜鸟、中区驿站
- 营业时间：08:00-20:00
- 备注：中区唯一驿站，取件高峰 12:00-13:00 和 18:00-19:00
