# CampusDash 前端

校园跑腿抢单市场工作台，基于 React 18、TypeScript 与 Vite。页面保留 Globex 工作台的布局层次，采用明黄、深色文字与白灰底的美团风格配色，覆盖发布、接单、任务跟进、资金记录与信用管理。

主黄 `#FFD100` 参考[美团官网](https://www.meituan.com/media)当前主题；浅黄、灰阶与金额橙为本项目适配色。品牌名称与校园插画保留 CampusDash。

## 本地运行

```bash
npm install
npm run dev
npm run build
```

开发页面默认在 http://localhost:5173，后端默认在 http://localhost:8080。Vite 将 `/api` 和 `/ws` 转发到后端。部署时也需要为这两个路径配置同源反向代理，并为 `/ws` 开启 WebSocket 转发。

## 演示身份

登录页可选择发单人 `1001`、跑腿同学“泡” `2001` / 跑腿同学 B `2002`、平台仲裁员 `9001`。身份登录需要后端在线，账户余额与权限以后端配置和数据为准。切换身份后重新加载页面数据，并重新建立消息连接。

## 页面与交互

| 页面 | 入口 | 功能 |
| --- | --- | --- |
| 任务广场 | `#/square` | 服务快捷入口、类型筛选、标题/编号搜索、悬赏排序、任务卡、教学演示 |
| 发布任务 | `#/publish` | 类型选择、需求描述、悬赏预设、金额校验、实时预览、发布反馈 |
| 我的任务 | `#/mine` | 发布/接单角色切换、状态筛选、任务搜索 |
| 任务详情 | `#/detail/:id` | 任务信息、状态时间线、悬赏、当前可执行操作与仲裁 |
| 我的钱包 | `#/wallet` | 可用与冻结余额、按方向/类型筛选记账流水 |
| 信用中心 | `#/credit` | 当前信用、规则、变动记录、校区榜单 |
| 消息中心 | `#/notifications` | 按日期分组的通知、类型筛选和关联任务 |

任务卡按类型/状态、需求、发布者/名额、悬赏/操作四层组织，金额与主要操作共用底栏。主跑腿账号 `2001` 的昵称统一显示“泡”，昵称只影响展示，不更改用户 ID 或权限。

页面统一提供加载、空列表、错误与重试状态。手机端导航使用抽屉，支持 Escape 关闭、焦点约束及返回触发按钮。界面尊重系统减少动态效果的偏好。

广场的“并发抢单演示”默认收起。执行会用演示身份真实抢占所选任务名额，仅用于观察浏览器少量并发结果，不代表服务端压测。

## 数据约定

- 操作按钮以服务端 `availableActions` 为准，前端不复制权限状态机。
- 任务、用户等长 ID 全程保留字符串；金额字段在请求边界显式转换为安全整数分。
- 列表接口默认返回最近 20 条，界面统计只表示当前加载结果，不代表全校总量。
- 钱包冻结额不是托管总额。记账流水可能含同一业务的复式两条记录，不能直接汇总成个人收入与支出。
- WebSocket 断开后自动重连，广场与任务详情保留轮询刷新；主动退出或切换身份会清理旧连接。
- 生产页面没有内置假任务、余额、距离或预计送达时间。

## 结构

- `src/App.tsx`：登录与应用路由。
- `src/components/TopBar.tsx`：侧栏、顶部导航、身份与钱包摘要。
- `src/components/ErrandCard.tsx` / `ActionButtons.tsx`：任务呈现与服务端驱动的业务操作。
- `src/components/Icon.tsx` / `CampusArt.tsx`：本地矢量图标与校园插画，不依赖远程素材。
- `src/pages/`：各业务页面及其独立样式。
- `src/api.ts` / `ws.ts`：请求边界、金额归一化、会话与连接管理。
- `src/styles.css`：统一设计变量、工作台布局和响应式样式。

```bash
python3 tests/ui_smoke.py
```

截图与结果放在 `verification/2026-10-14/`。该验收只验证前端与接口契约，不代替真实后端、数据库、资金或消息链路联调。

## 2026-10-14 真实业务验收

57 项前端 mock 检查、35 项真实浏览器流程检查、29 项真实 API/MQ 检查、3 项定向 WebSocket 检查及 59 项后端单元/本地测试全部通过。真实浏览器流程包含发布、接单、确认、取货、送达、结算、取消退款和争议仲裁，业务写入全部通过 UI 点击完成，并核对真实钱包、信用及消息。生产构建通过。

范围、资金一致性结果、MQ 时序、未重跑项目及复跑命令见[完整验收记录](verification/2026-10-14/README.md)。演示登录仍按用户 ID 选择身份，属于教学认证模式。
